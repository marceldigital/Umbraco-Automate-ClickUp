# Umbraco Automate ClickUp

OAuth-based ClickUp provider for Umbraco Automate. Create ClickUp tasks from any Umbraco
Automate workflow, using a ClickUp connection configured per Workspace.

```bash
dotnet add package Umbraco.Community.Automate.ClickUp
```

## Actions

- [**All actions**](actions/index.md) — the full list, with aliases and what each one does
